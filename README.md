# CMG

Plataforma de gestão e acompanhamento de atividades de campo para o contrato Torre Meridian.

## O que é este projeto?

Este sistema foi pensado para organizar o trabalho de equipe em campo, centralizando as atividades, o andamento de cada tarefa e as evidências registradas durante a execução.

A ideia principal é simples: o analista recebe atividades, registra o que foi feito, envia fotos e atualiza o status. Já a gestão acompanha tudo em tempo real, vendo o que está pendente, em andamento e concluído.

## Como funciona

### 1. Acesso

A pessoa entra na plataforma com o ID da empresa e a senha.

Após o login, o sistema identifica o perfil da pessoa e direciona para a área correta:

- Analista: visualiza as atividades delegadas
- Gestão: acompanha o painel geral da equipe

### 2. Atividades delegadas

As atividades aparecem em uma lista organizada por status, como:

- pendente
- em andamento
- pausada
- concluída

Cada item mostra:

- título da atividade
- tipo de serviço
- local
- data programada
- descrição do trabalho

Ao abrir uma atividade, o usuário pode preencher o registro de execução, informar detalhes do serviço e atualizar o andamento.

### 3. Evidências fotográficas

Durante a execução, é possível anexar fotos diretamente do celular ou da galeria.

Cada imagem pode receber uma legenda descrevendo o que foi visto ou realizado. Isso ajuda a documentar a execução com provas visuais e mantém um histórico organizado.

### 4. Status e conclusão

O status da atividade pode ser atualizado conforme o trabalho avança.

Quando a tarefa está concluída, o sistema libera o fechamento do registro e permite gerar o relatório final.

### 5. Painel de gestão

A área de gestão mostra indicadores gerais, como:

- quantidade total de atividades
- atividades pendentes
- em execução
- concluídas

Também é possível filtrar por data e exportar os dados em formatos prontos para uso, como PDF e Word.

## Quem usa

- Analistas de campo
- Supervisores e gestão
- Equipe responsável por acompanhamento e documentação das atividades

## Objetivo do projeto

O projeto tem como foco reduzir a burocracia, centralizar as informações e dar visibilidade real do trabalho em campo, sem depender de planilhas manuais ou acompanhamento disperso.

## Como usar

1. Faça login na plataforma.
2. Acesse as atividades que foram delegadas para você.
3. Abra uma atividade e atualize o status.
4. Preencha os dados da execução.
5. Anexe fotos quando necessário.
6. Conclua a tarefa e gere o relatório quando solicitado.

## Resumo

Em resumo, este projeto funciona como uma ferramenta de acompanhamento operacional: organiza as tarefas, registra a execução, guarda evidências e ajuda a gestão a acompanhar tudo de forma centralizada e prática.
